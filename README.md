# Harborline Secure Network Access Lab

An animated introduction to VPNs, network segmentation, Zero Trust access checks and network hardening. The lab has 25 guided challenges and is designed for a 65–90 minute session including reflection. Learners can pause the animations, retry challenges and download a PNG certificate after completing all 25.

Open `index.html` in a modern browser. The simulation uses fictional requests and configuration records. Its files run locally and on GitHub Pages without a build.

## GitHub Pages files

Place these files together in the site’s publishing folder.

- `index.html`
- `styles.css`
- `cases.js`
- `app.js`
- `STUDENT-GUIDE.txt`

Share `INSTRUCTOR-ANSWER-KEY.txt` separately. Student progress is saved in browser storage for the current site.
